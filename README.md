# 幕末人物・勢力ナビ

幕末(1853〜1869年)の人物・勢力・事件を、**時点を切り替えながら**追える学習ツールです。

同じ人物でも、年が変われば名乗りも所属も役職も変わります。「1862年の徳川慶喜は何と呼ばれ、どこに属し、何をしていたか」を
選んだ時点ごとに引き直して表示します。人物 ⇄ 勢力 ⇄ 事件 ⇄ 場所を相互に行き来でき、事件の因果関係と人物の相関を図でも追えます。

ビルド不要の素の HTML / CSS / JavaScript で、**外部ライブラリを一切使っていません**。

## このツールの方針 — 裏づけのないことは書かない

歴史の学習ツールでいちばん困るのは、**もっともらしいのに根拠のない記述**です。ここでは次の作り方をしています。

- **すべての値に出典を紐づける。** 収録している出典の大半は国立国会図書館・国立公文書館・
  各県の公文書館や図書館など、公的機関が公開している資料です。
- **出典は「URL を挙げる」だけにしない。** 資料の原文から**逐語で引用文を取り、その引用が登録した値を本当に支持しているか**を
  1項目ずつ確かめています。画面の各項目からは、その根拠となった引用文まで辿れます。
- **推測で埋めない。** 資料から確かめられなかったことは書きません。各項目には、根拠になった資料の逐語引用を添えています。
- **年代の表記に注意を払っています。** 旧暦の「慶応3年12月」は西暦では1868年1月にあたることがあり、
  年をまたぐ日付は取り違えの温床です。換算が確定できないものは、粒度を落として記録しています。

## 動かす

データを `fetch` で読むため、`file://` で直接開くと動きません(CORS)。静的サーバを1つ立ててください。

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

ブラウザで http://localhost:8765/ を開きます。

## データについて

`data/*.json` が中身です。各値には出典 ID が紐づいており、`data/sources.json` に URL・引用文・取得日が入っています。
引用文は資料原文からの逐語引用で、**離れた箇所をつないだり中略記号で連結したりしていません**(連結すると、原文には存在しない
文が出典として登録されてしまうため)。

引用した資料の著作権は各機関に帰属します。このツールは資料そのものを再配布せず、出典の URL と、
値の裏づけに必要な範囲の引用のみを収録しています。
